# 恋爱塔罗 · 设计与实现说明

## 一句话

24 道单选题 → 8 张塔罗牌面之一 → 结果页有牌面、长文、标签、八维图、配对。

纯静态：一个 HTML + 一个 CSS + 三个 JS，没有框架、没有构建、没有后端、没有第三方接口。丢进 GitHub Pages 就能用。

## 目录

```
tarot/index.html           页面骨架（四个 screen）
tarot/assets/css/style.css       全部样式
tarot/assets/js/data.js          ★ 题库 + 8 张牌 + 首页文案（要改内容只改这个）
tarot/assets/js/art.js           牌面插画（手写内联 SVG）
tarot/assets/js/app.js           流程、计分、分享逻辑
tarot/assets/og.png              分享缩略图（1200×630）
tools/check-data.js        题库自检（均衡、缺字段、SVG 生成）
tools/shot.js              无头 Chrome 截图自检
tools/live-check.js        线上站点自检
开发文档/预览/             截图产物
```


## 页面结构

四个 `.screen` 绝对定位叠在 `.phone` 里，靠 `.active` 切换，用 CSS transition 做淡入。没有路由，也没有滚动到底部的换屏。

1. **cover**：牌面大字 + 三张叠起来的牌背 + 开始按钮
2. **quiz**：顶部返回 / 进度 / 进度条，中间牌背小图 + 题目标题，下面三个选项
3. **result**：牌面渐变头图 + 牌名 + 一句话 + 长文 + 标签 + 次要牌 + 八维柱状图 + 配对框 + 三个按钮
4. **gallery**：8 张牌全部列出

## 计分

`answers` 记录每题选了哪张牌，`tally()` 现算，不累加。这样回退改答案不会算错（原版是点一次 +1、回退 -1，容易出错）。

1. 每张牌被选中的次数 = 得分
2. 最高分是主牌
3. 并列最高时随机取一个当主牌，其余显示为「你身上还带点 X 的影子」，最多显示 2 个
4. 八维柱状图：每张牌的票数 ÷ 最高票数

**均衡要求**：24 题 × 3 选项 = 72 个选项位，8 张牌 × 9 = 72。所以每张牌应该正好出现 9 次，`tools/check-data.js` 会断言这一点。如果不等，某些牌会更难被抽到，结果分布就歪了。

当前题库按 8 个场景族 × 3 题组织，每个族固定用 3 张牌，保证均衡：

| 04–06 吵架与和好 | 太阳 / 星星 / 皇后 |

## 分享

`分享给朋友` 生成 `?r=<牌面 id>` 的链接，打开后直接进结果页，顶部黑条显示「朋友抽到的牌是「太阳 · 喜欢就直说的人」」，按钮变成「我也要抽一张」。

这一点比原版完整：原版页面上写了「分享链接会带上你的结果」，但实际分享的是裸链接，朋友点开看到的是封面。这里真的做了。

优先走 `navigator.share`（手机弹系统分享面板），不支持就复制文本，复制也失败就弹链接让人长按复制。

## 插画

`art.js` 里 8 个函数各返回一段 SVG 片段，坐标系 120 × 180，外面的牌框、罗马数字、牌名由 `cardSVG()` 统一套。想换成自己的画，只替换 `MOTIFS` 里对应函数即可，不用改样式——描边颜色取 `CARDS[key].c`，粗细、端点样式都在 `.ca-motif` 里。

## 已知取舍

- **没有「已测试人数」**。原版靠第三方计数接口 `apizero.cn`，那个域名随时会挂，而且会把访客 ID 发给第三方。这里不接。非要显示的话，建议自己写个 Cloudflare Worker / Vercel Function 计数，再把数字塞进封面。
- **没有投票页**。原版投票也是写进同一个第三方接口。没有后端时投票只是本地 `localStorage`，对站长没有价值，所以删掉。
- **没有埋点**。需要看数据就自己加（百度统计、Umami、Cloudflare Web Analytics 都行）。
- **牌面是线条插画**，不是 Lottie 动画。原版首页的猫是 Lottie JSON，体积大且需要引库；这里换成静态 SVG，全站没有任何外部请求。

## 验证

```powershell
node tools/check-data.js   # 题库均衡 / 字段完整性 / SVG 能生成
node tools/shot.js         # 无头 Chrome 跑一遍流程，截图到 开发文档/预览/
```

`tools/shot.js` 里 Chrome 路径是写死的，换机器要改 `CHROME` 常量。它通过 CDP 连本机 Chrome，点按钮、截图，并收集页面报错。

## 换一个测评主题要改什么

1. `data.js` 的 `CARDS`：8 个原型，每个要有 `n`（名字）、`t`（一句话）、`c` / `c2`（主色）、`tags`、`d`（长文）、`pair` / `combo` / `buddy` / `buddyWhy`
2. `data.js` 的 `QUIZ`：24 题，每题 3 个选项，第二个元素填 `CARDS` 的 key，注意保持每张牌 9 次
3. `data.js` 的 `DIMS`：八维图的顺序和简称
4. `data.js` 的 `COPY`：封面文案、按钮文案
5. `art.js` 的 `MOTIFS`：8 张插画（不换也行，用现有符号）
6. 跑 `node tools/check-data.js` 确认没错
